# Where to find data

| What | Best source | Backup |
|---|---|---|
| RHP / DRHP (financials, OFS split, objects of issue, risks, peers) | sebi.gov.in → Filings → Public Issues | Company's IPO page, BRLM (lead manager) site |
| Price band, dates, lot size | nseindia.com / bseindia.com IPO pages | chittorgarh.com |
| Live & final subscription (QIB / NII / retail) | nseindia.com, bseindia.com | chittorgarh.com, moneycontrol.com |
| Anchor investor list | Exchange announcement (anchor allocation) | chittorgarh.com |
| GMP (unofficial) | investorgain.com, ipowatch.in | chittorgarh.com |
| Market sentiment | Nifty / Sensex / India VIX, sector index on NSE | moneycontrol.com, economictimes.com |
| Listing price & volume | NSE / BSE quote page on listing day | moneycontrol.com |
| Peer valuations | RHP "Basis for issue price" section | screener.in |

NSE pages need JavaScript — use Claude in Chrome for them.

## Data checklist
- [ ] Mainboard / SME, exchange
- [ ] Price band, lot size, issue size (fresh vs OFS split in ₹ cr)
- [ ] Dates: open, close, allotment, listing
- [ ] 3-year revenue, PAT, EBITDA margin, operating cash flow, debt/equity
- [ ] Issue P/E (post-issue) and 2–4 peer P/Es
- [ ] Objects of the issue (use of funds)
- [ ] Promoter holding pre / post, any litigation
- [ ] Subscription by category (QIB, NII/HNI, retail, employee) — with timestamp
- [ ] Anchor investors and amount
- [ ] GMP today and trend over last few days — with timestamp
- [ ] Nifty, sector index, VIX over last 5–10 sessions
- [ ] (If listed) open, high, low, close on listing day, volume, vs issue price and vs last GMP
